PROJECT NEW ERA — Minimal Android App

What it does:
- Shows one full-screen solid blue screen.
- Shows centered white text: PROJECT NEW ERA
- Solid blue launcher icon with no text.
- No internet permission.
- No storage permission.
- No extra screens or features.

Build in Android Studio:
1. Open this folder as an existing Android project.
2. Let Android Studio sync/download its required Gradle/Android build components.
3. Use Build > Build APK(s).
4. The APK will be under app/build/outputs/apk/debug/.

Application ID: com.projectnewera
Version: 1.0 (versionCode 1)
Minimum Android: 6.0 / API 23
Target SDK: 35
